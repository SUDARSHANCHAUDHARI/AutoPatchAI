# Security Policy

## Supported Versions

This project is currently in early MVP development. Security fixes apply to the default branch.

## Reporting a Vulnerability

Do not open public issues for sensitive security reports. Contact Sudarshan privately at sunny.sudarshan@gmail.com with:

- affected component
- impact summary
- reproduction steps
- suggested remediation, if known

## Security Rules

- Do not commit secrets, tokens, private logs, customer data, SSH keys, or signing material.
- Use only authorized systems, lab data, and owned infrastructure.
- Keep generated reports free of sensitive raw credentials or personal data.
